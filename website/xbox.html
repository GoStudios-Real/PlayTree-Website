Status: Xbox controller supported now. Microsoft Store/Xbox console listing requires MSIX packaging and Partner Center submission.

How to get it on Xbox / Microsoft Store

  1. Build the Windows EXE with playtree/build_playtree.bat.
  2. Package as MSIX using Microsoft MSIX Packaging Tool (playtree/build_xbox_msix.bat helps prep).
  3. Create/reserve PLAYTREE in Microsoft Partner Center.
  4. Upload MSIX, complete age rating, store listing, and Xbox device family/certification requirements.
  5. Test on Xbox Dev Mode before submission.

Already included

  • Xbox controller button mapping and on-screen prompts
  • Gamepad input support in gameplay/menus
  • Windows build pipeline for MSIX packaging
