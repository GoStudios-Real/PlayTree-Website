## Platform

web

## Users

Players interested in downloading and learning about PLAYTREE, plus existing GoStudios account users who want to inspect progress.

## Product Purpose

Present the PLAYTREE fantasy adventure game clearly, communicate its campaign and systems, and help visitors download or continue to a platform-specific experience.

## Positioning

PLAYTREE combines exploration, combat, base building, creature taming, crafting, and multiplayer progression in a stylized fantasy RPG.

## Operating Context

The product is a Python/Pygame game with Windows as the released platform, Android builds in progress, and Xbox/MSIX work documented in the repository. The official site is a static PWA with account interactions stored locally and GitHub Pages deployment configuration.

## Capabilities and Constraints

- Real-time combat across 5 documented player classes
- 4 campaign rounds with bosses
- Multiplayer lobby, base building, crafting, pet taming and evolution
- Existing local-account interface and PWA install behavior
- Static HTML/CSS/JavaScript implementation
- Download links and executable files may be placeholders or external; never invent availability
